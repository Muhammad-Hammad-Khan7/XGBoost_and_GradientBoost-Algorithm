# XGBoost and Gradient Boosting

This project explores Gradient Boosting and XGBoost, two powerful machine learning algorithms used for prediction and classification tasks.

## Technologies
- Python
- NumPy
- Pandas
- Scikit-learn
- XGBoost
- Jupyter Notebook

## Topics Covered
- Gradient Boosting
- XGBoost
- Model Training and Evaluation

## Run the Project

```bash
pip install numpy pandas scikit-learn xgboost jupyter
```

Open the notebook:

```bash
jupyter notebook XGboost_and_GradientBoost.ipynb
```
